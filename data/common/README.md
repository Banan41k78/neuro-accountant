# data/common

Общая база знаний. Универсальные нормы, которые применимы к любой организации.

## Что кладём сюда

- **НК РФ** — главы 21 (НДС), 25 (налог на прибыль), 26.2 (УСН), 30 (налог на имущество)
- **ПБУ / ФСБУ** — положения по бухгалтерскому учёту
- **Письма Минфина и ФНС** — разъяснения по спорным вопросам
- **Учебники и методички** — например, PDF УрФУ по бухучёту
- **Инструкции 1С** — по типовым операциям
- **FAQ** — свои заметки и ответы на частые вопросы

## Поддерживаемые форматы

`.txt`, `.md`, `.pdf` — обрабатываются автоматически.

Частично автоматически:

python -m src.ingest.fetch_common
