# data

Источники для индексации и обучения.

## Структура

| Папка / файл | Назначение |
|---|---|
| `common/` | Общая база: НК РФ, ПБУ, ФСБУ, учебники, инструкции 1С |
| `contour/` | Контурные базы по организациям. По одной подпапке на клиента |
| `raw/` | Кэш скачанного (Google Docs, веб-страницы). Не индексируется |
| `train.jsonl` | Датасет для LoRA-дообучения |
| `eval.jsonl` | Эталонные QA для оценки качества |

## Принципы

- **common** — универсально, переиспользуется между клиентами.
- **contour** — приватно, у каждой организации своя папка.
- **raw** — временное, можно удалять.
